## 🚀 تایبەتمەندییەکان

- 🎯 **وتەی هەڕەمەکیی ڕۆژانە**  
  بە یەک دەستلێدان وتەی هاندەری نوێ وەربگرە.

- ⭐ **دڵخوازەکان**  
  ئەو وتانەی خۆشت دەوێن پاشەکەوت بکە — و هەر کاتێک ویستت بەڕێوەیان ببە یان بیانسڕەوە.

- 🕓 **مێژووی وتەکان**  
  لیستی هەموو ئەو وتانە ببینە کە لەم دانیشتنەدا بینیوتن.

- 🎨 **دەستکاریکردنی ڕووکار**

  - لە نێوان دۆخی **تاریک** و **ڕووناک** بگۆڕە.
  - **ڕەنگی سەرەکیی** دڵخوازت هەڵبژێرە بۆ ستایلێکی تایبەت بە خۆت.

- 💾 **ڕێکخستنە پاشەکەوتکراوەکان**  
  ڕووکار، ڕەنگی سەرەکی و دڵخوازەکانت بە `shared_preferences` پاشەکەوت دەکرێن و خۆکارانە دەگەڕێنرێنەوە.

- 🖼 **ڕووکاری نوێ**  
  دیزاینێکی پاک و گونجاو بە جووڵەی تایبەتی Flutter و ویجێتەکانی Material و Cupertino.

- 📋 **کۆپیکردن**  
  بە یەک دەستلێدان وتەکان کۆپی بکە بۆ هاوبەشیکردن یان پاشەکەوتکردن.

- 📱 **پشتگیریی هەموو پلاتفۆرمەکان**  
  لەسەر **Android**، **iOS** و **Flutter desktop** بە نەرمی کار دەکات.


## دەستپێکردن

1. **کۆپیکردنی ڕیپۆزیتۆرییەکە**

   ```sh
   git clone <https://github.com/Ali-Umed/quote-generator.git>
   cd Flutter_Quote_Generator-main
   ```

2. **دابەزاندنی پێداویستییەکان**

   ```sh
   flutter pub get
   ```

3. **کارپێکردنی ئەپەکە**

   ```sh
   flutter run
   ```
