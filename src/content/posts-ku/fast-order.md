---
title: "Fast Order - ئەپی داواکردنی پیتزا"
---

Fast Order **ئەپێکی گونجاوی داواکردنی پیتزایە** کە بە **React.js** دروستکراوە، و گواستنەوەی نوێ لە نێوان پەڕەکاندا، ڕووکارێکی پاک و بەڕێوەبردنێکی کارای داتای ئەپەکەی (state) تێدایە.


## ✨ تایبەتمەندییەکان

- 🍕 **داواکردنی ئاسانی پیتزا** – ناو، ناونیشان و شوێنەکەت بنووسە
- ⏱️ **کاتی خەمڵێنراوی گەیشتن** – کاتی گەیاندن ڕاستەوخۆ ببینە
- 🧭 **گواستنەوەی نەرم** – بە React Router لەگەڵ `useFetch` و `actionLoader`
- 📦 **بەڕێوەبردنی state** – بە شێوەیەکی ڕێکوپێک بە Redux Toolkit
- 📱 **ڕووکاری گونجاو** – دیزاینی گونجاو بۆ مۆبایل بە Tailwind CSS
- 🎯 **ڕووکاری ئاسان** – ئەزموونێکی خێرا و سادە بۆ داواکردن


## 🛠️ تەکنەلۆژیاکان

- **React.js** – دروستکردنی ڕووکار بە کۆمپۆنێنت
- **React Router** – بۆ گواستنەوەی نەرم لە نێوان پەڕەکانی ئەپەکەدا
- **Redux Toolkit** – بەڕێوەبردنی state بە سادەیی و بەهێزی
- **Tailwind CSS** – بۆ ستایلی نوێ و گونجاو
- **JavaScript** – لۆجیکی ئەپەکە


## 🔑 بەشە سەرەکییەکان

- **فۆرمی داواکاری** – زانیاریی بەکارهێنەر وەردەگرێت (ناو، ناونیشان، شوێن)
- **لیستی پیتزا** – پیتزا بەردەستەکان و هەڵبژاردنەکانی دەستکاریکردن پیشان دەدات
- **کورتەی داواکاری** – وردەکاریی داواکاری و کاتی گەیاندن پیشان دەدات
- **گواستنەوە** – بە React Router بۆ گۆڕینی خێرای پەڕەکان


## ⚙️ دەستپێکردن

```bash
# 1. Clone the repo
git clone https://github.com/Ali-Umed/fast-order.git

# 2. Go to the project directory
cd fast-order

# 3. Install dependencies
npm install

# 4. Start the dev server
npm start
```
