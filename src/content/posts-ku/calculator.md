# 🧮 ئەپی ژمێرەر

ژمێرەرێکی نوێیە کە دەتوانیت ڕووکارەکەی بگۆڕیت، و بە **React**، **TypeScript** و **Tailwind CSS** دروستکراوە. بە سادەیی و بە گرنگیدان بە ڕووکار و ئەزموونی بەکارهێنەر دیزاین کراوە.


## ✨ تایبەتمەندییەکان

- کردارە سەرەکییەکان: **کۆکردنەوە**، **لێدەرکردن**، **لێکدان**، **دابەشکردن**
- **ڕێژەی سەدی**، **پاککردنەوە** و **سڕینەوە**
- پشتگیریی **دۆخی تاریک** و **دۆخی ڕووناک**
- **6 ڕووکار**:
  - 3 بۆ دۆخی تاریک
  - 3 بۆ دۆخی ڕووناک


## 🚀 بینینی ڕاستەوخۆ

👈 [لێرە تاقی بکەرەوە](https://calculator-phi-black.vercel.app/)


## 🛠️ تەکنەلۆژیاکان

- **React**
- **TypeScript**
- **Tailwind CSS**


## ⚙️ دەستپێکردن

```bash
# Clone the repository
git clone https://github.com/your-username/calculator-app.git

# Install dependencies
npm install

# Start the development server
npm run dev
```
