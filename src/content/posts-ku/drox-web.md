**drox.cards** ماڵپەڕی فەرمیی ئەپی کارتی دڵسۆزیی دیجیتاڵی **درۆکس**ە. ڕوونی دەکاتەوە درۆکس چۆن بۆ کڕیار و بزنس کاردەکات، شاشە ڕاستەقینەکانی ئەپەکە پیشان دەدات و سەردانکەران دەنێرێت بۆ ستۆری گونجاو بۆ دابەزاندنی.

هەموو ماڵپەڕەکەم بە **Next.js 16** و **React 19** دیزاین و دروستکردووە.


## ✨ تایبەتمەندییە سەرەکییەکان

- **پەڕەی سەرەکی**: بەشی سەرەکی، شاشە ڕاستەقینەکانی ئەپ، ڕێنمایی چوار هەنگاوی "چۆن کاردەکات"، بوارەکان، کارتە باوەکان و پرسیارە باوەکان.
- **پەڕەی بزنس**: هەموو ئەوەی دوکانێک پێویستی پێیەتی بۆ بەڕێوەبردنی کارتی دڵسۆزی، ئۆفەر، سکانەری کارمەندان و ئاماری ڕاستەوخۆ لە درۆکس.
- **پەڕەی کارت**: هەر کارتێکی دڵسۆزی پەڕەی تایبەتی خۆی هەیە بۆ هاوبەشکردن لە `drox.cards/card/…`.
- **پەڕەی دابەزاندن**: بەستەری App Store و Google Play بۆ iPhone و Android.
- **سێ زمان**: کوردیی سۆرانی، عەرەبی و ئینگلیزی لەگەڵ ڕووکاری ڕاست بۆ چەپ، بە next-intl.
- **SEO**: سایتماپ، robots، وێنەی Open Graph و ناوەڕۆکی گونجاو بۆ گەڕان بە هەموو زمانەکان.
- **پەڕەی یاسایی**: سیاسەتی تایبەتمەندی و سڕینەوەی هەژمار، وەک ستۆرەکان داوای دەکەن.
- **ڕووکاری ڕووناک و تاریک** لەگەڵ جووڵەی نەرمی Framer Motion، لەسەر هەموو قەبارەیەکی شاشە.


## ⚡ تەکنەلۆژیاکان

| بەش | تەکنەلۆژیا |
| :--- | :--- |
| **فرەیموۆرک** | Next.js 16، React 19، TypeScript |
| **ستایل** | Tailwind CSS 4، Framer Motion |
| **زمانەکان** | next-intl (کوردی، عەرەبی، ئینگلیزی) |
| **SEO** | سایتماپ، robots، وێنەی Open Graph |
