بەخێربێیت بۆ **Weather App** – ئەپڵیکەیشنێکی نوێ و گونجاو کە بە React دروستکراوە و ڕێگەت پێدەدات پێشبینیی کەشوهەوای هەر شوێنێک ڕاستەوخۆ ببینیت.


## ✨ تایبەتمەندییەکان

- **کەشوهەوای ڕاستەوخۆ** – دەستبەجێ زانیاریی نوێی کەشوهەوا وەربگرە.
- **پێشبینیی 15 ڕۆژ** – پێشبینیی درێژخایەن ببینە و بۆ وردەکاریی زیاتر کلیک لە کارتی هەر ڕۆژێک بکە.
- **دۆزینەوەی شوێن** – بە کلیککردن لەسەر ئایکۆنی شوێن، کەشوهەوای شوێنی ئێستات ببینە.
- **دیزاینی گونجاو** – لەسەر مۆبایل، تابلێت و کۆمپیوتەر بە جوانی کار دەکات.
- **دۆخی ڕۆژ/شەو** – گۆڕین لە نێوان ڕووکاری ڕووناک و تاریکدا.
- **زانیاریی ورد** – پلەی گەرمی، شێ، خێرایی با، دۆخی کەشوهەوا و زیاتر ببینە.
- **گەڕان** – بە ئاسانی بە ناوی شار یان شوێن بەدوای کەشوهەوادا بگەڕێ.


## 🛠️ تەکنەلۆژیاکانی بەکارهاتوو

- **Vite** – ئامرازێکی خێرا و نوێ بۆ فرۆنتئێند
- **React** – فرەیموۆرکی ڕووکار
- **TypeScript** – گەشەپێدان بە جۆری داتای پارێزراو
- **Tailwind CSS** – ستایلی utility-first بۆ دیزاینی گونجاو
- **React Icons** و **FontAwesome** – کتێبخانەی ئایکۆن بۆ ڕووکار


## ⚙️ دەستپێکردن

بۆ کارپێکردنی ئەپەکە لەسەر کۆمپیوتەرەکەت ئەم هەنگاوانە بگرەبەر:

```bash
# 1. Clone the repository
git clone https://github.com/Ali-Umed/weather-app.git
cd weather-app

# 2. Install dependencies
npm install

# 3. Add your API key
# Get one from https://www.visualcrossing.com/
# (Or use the one provided in the code – it's free to use)

# 4. Start the development server
npm start
```
