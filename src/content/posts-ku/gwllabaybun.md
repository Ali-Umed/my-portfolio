# 🌼 گوڵە بەیبوون | Gula Baibun

**گوڵە بەیبوون** پلاتفۆرمێکی نوێ و یاریئامێزی **فێربوونی زمانی ئینگلیزییە بۆ کوردزمانان**، و ئامانجی ئەوەیە فێربوونی ئینگلیزی بۆ ئاخێوەرانی کوردی سروشتی، خۆش و ئاسان بکات.

بە تێکەڵکردنی کارتی وشەی کارلێککار بێ دواکەوتن، یاریی بچووک، بەدواداچوونی ڕۆژانی بەردەوامی و ڕیزبەندیی کێبڕکێ، گوڵە بەیبوون فێربوونی ڕۆژانەی ئینگلیزی دەکات بە خووێکی سەرنجڕاکێش.

> **🌼 ئینگلیزی بە هەمان سروشتی و تازەیی گوڵە بەیبوون فێربە — هەر کاتێک، لە هەر شوێنێک، ئۆنلاین!**

## 🚀 تایبەتمەندییە سەرەکییەکان

### 🎮 یارییە کارلێککارەکانی زمان
- **گونجاندنی هاوواتا و دژواتا**: وشە پەیوەندیدار یان دژەکان پێکەوە ببەستەوە بۆ قووڵکردنەوەی وشەزانینت.
- **تاقیکردنەوەی کارتی وشە**: لەسەر وشە، کردار و دەستەواژە باوەکانی ئینگلیزی ڕاهێنان بکە.
- **Hangman و HeadsUp**: یاریی خێرای دۆزینەوەی وشە بۆ فێربوونی تاکەکەسی یان بە کۆمەڵ.
- **گەڕانی وشە و مەتەڵ**: وشە شاراوەکان بدۆزەرەوە کە بەپێی بابەت ڕێکخراون.

### 🔥 یاری و هاندانی ڕۆژانە
- **نەخشەی بەردەوامیی ڕۆژانە**: ببینە چۆن هەر ڕۆژێکی فێربوون ڕۆژژمێرەکەت ڕووناک دەکاتەوە، و بەردەوامیی 50+ ڕۆژەکەت بپارێزە!
- **XP، ئاست و دراو**: بە هەر وەڵامێکی دروست خاڵی ئەزموون کۆبکەرەوە و تایبەتمەندیی تایبەت بکەرەوە.
- **مێدالی ئاڵنگاری**: ئامانجە هەفتانەکان تەواو بکە و نیشانەی دیجیتاڵیی تایبەت کۆبکەرەوە.
- **ڕیزبەندیی گشتی**: لەگەڵ هەزاران فێرخوازی ئینگلیزی لە سەرانسەری کوردستان کێبڕکێ بکە.

### 📚 کتێبخانەیەکی تەواوی وشە
- **فێربوون بەپێی بەش**: کردارەکان، دەستەواژەی ڕۆژانە، ئینگلیزیی بازرگانی، گەشت و زاراوەی کولتووری.
- **وەرگێڕانی سروشتیی کوردیی سۆرانی**: نموونەی گونجاو لەگەڵ ناوەڕۆک و وەرگێڕانی وردی کوردی (`ckb`).

### 🌐 بۆ هەموو پلاتفۆرمەکان و ئەزموونێکی جوان
- **ڕووکاری فرەزمان**: گۆڕینی دەستبەجێ لە نێوان **کوردیی سۆرانی**، **ئینگلیزی** و **عەرەبی**.
- **دۆخی تاریک و ڕووناک**: ڕووکاری تاریکی نەرم لەسەر بنەمای ڕەنگی HSL، لەگەڵ کارتی شووشەیی و جووڵەی وردی زیندوو.
- **کارایی ڕەسەن**: بە Flutter دروستکراوە بۆ جووڵەی نەرمی 60fps لەسەر iOS و Android.


## ⚡ پێکهاتەی تەکنەلۆژیا

| بەش | تەکنەلۆژیا و فرەیموۆرکەکان |
| :--- | :--- |
| **ئەپی مۆبایل** | Flutter (Dart `^3.6`)، بەڕێوەبردنی state بە `flutter_bloc`، Hive و SQLite، Secure Storage |
| **وێب و پەڕەی ناساندن** | Next.js 16 (App Router)، React 19، Tailwind CSS v4، Framer Motion، `next-intl` |
| **باکئێند (API)** | Laravel 12 (PHP 8.4)، چوونەژوورەوە بە Laravel Sanctum، REST API |
| **پانێڵی بەڕێوەبەر** | داشبۆردی Filament v4 بۆ بەڕێوەبردنی ناوەڕۆک، بەشەکان و ئاماری بەکارهێنەران |
| **فرەزمانی** | پشتگیریی کوردیی سۆرانی (`ckb`)، ئینگلیزی (`en`) و عەرەبی (`ar`) |


## 🏆 یاری لە فێربووندا چۆن کار دەکات

1. **ڕاهێنانی ڕۆژانە**: هەموو ڕۆژێک وانەکان تەواو بکە.
2. بە تەواوکردنی وانەکان **XP** وەردەگریت و **ئاستەکەت بەرز دەبێتەوە**، ئینجا لە **ڕیزبەندیی گشتی** سەردەکەویت.
3. بە **بەردەوامیی ڕۆژانە**، ڕۆژەکانت لە **نەخشەی ڕۆژژمێر** ڕووناک دەبنەوە.
4. بە تەواوکردنی **ئاڵنگارییەکان**، **مێدال و دراو** بەدەست دەهێنیت.
