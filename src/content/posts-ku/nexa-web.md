**nexa-iq.com** ماڵپەڕی فەرمیی ئەپی پەروەردەیی **نێکسا**یە. ئەپەکە بە قوتابیان و قوتابخانەکان دەناسێنێت، شاشە ڕاستەقینەکانی پیشان دەدات و سەردانکەران دەنێرێت بۆ App Store یان Google Play.

هەموو ماڵپەڕەکەم بە **Next.js 16** و **React 19** دیزاین و دروستکردووە.


## ✨ تایبەتمەندییە سەرەکییەکان

- **پەڕەی سەرەکی**: بەشی سەرەکی لەگەڵ دوگمەی ستۆرەکان، نمایشی شاشەکانی ئەپ و تایبەتمەندییە سەرەکییەکانی.
- **پەڕەی دەربارە و پەیوەندی**: ئامانج و دیدی نێکسا، لەگەڵ ئیمەیڵ، ژمارەی تەلەفۆن و ناونیشانی نووسینگە.
- **پەڕەی دابەزاندن و کۆدی QR**: یەک شوێن بۆ وەرگرتنی ئەپەکە لەسەر iPhone یان Android.
- **پەڕەی یاسایی**: سیاسەتی تایبەتمەندی، مەرج و ڕێساکان و سڕینەوەی هەژمار، وەک ستۆرەکان داوای دەکەن.
- **سێ زمان**: کوردیی سۆرانی، عەرەبی و ئینگلیزی لەگەڵ ڕووکاری ڕاست بۆ چەپ، بە next-intl.
- **ڕووکاری ڕووناک و تاریک** لەگەڵ هێڵی پێشکەوتنی سکرۆڵ و جووڵەی نەرمی Framer Motion، لەسەر هەموو قەبارەیەکی شاشە.


## ⚡ تەکنەلۆژیاکان

| بەش | تەکنەلۆژیا |
| :--- | :--- |
| **فرەیموۆرک** | Next.js 16، React 19، TypeScript |
| **ستایل** | Tailwind CSS 4، Framer Motion، next-themes |
| **زمانەکان** | next-intl (کوردی، عەرەبی، ئینگلیزی) |
