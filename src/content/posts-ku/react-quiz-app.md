---
title: "React Quiz App - ئەپی پرسیار و وەڵام"
---

ئەپێکی نوێی پرسیار و وەڵامە کە بۆ مۆبایل گونجاوە و بە **React**، **Vite** و **Tailwind CSS** دروستکراوە.
چەندین بەشی پرسیار، دۆخی ڕووناک/تاریک، سیستەمی خەڵاتی دراو، هەژماری بەکارهێنەر بۆ بەدواداچوونی پێشکەوتن و جووڵەی نەرمی تێدایە.


## ✨ تایبەتمەندییەکان

- 🧠 **چەند بەشێکی جیاواز** – پرۆگرامسازی، وەرزش، بیرکاری، مێژوو، جوگرافیا
- 🔄 **پرسیاری هەڕەمەکی** – لە هەر یارییەکدا پرسیاری جیاواز
- 🌙 **دۆخی ڕۆژ/شەو** – گۆڕین لە نێوان ڕووکاری ڕووناک و تاریکدا
- 💰 **سیستەمی دراو** – بۆ هەر وەڵامێکی دروست خەڵات وەربگرە
- 🖼️ **جووڵەی نەرم** – گواستنەوە و کاریگەریی نوێ لە ڕووکاردا
- 📱 **دیزاینی گونجاو** – لەسەر هەموو قەبارەیەکی شاشە کار دەکات
- 🔐 **هەژماری بەکارهێنەر** – هەژمار دروست بکە و پێشکەوتنەکانت بەدوادا بچۆ


## 🛠️ تەکنەلۆژیاکان

- ⚛️ [React](https://react.dev/) – دروستکردنی ڕووکار
- ⚡ [Vite](https://vitejs.dev/) – ئامرازێکی زۆر خێرا بۆ فرۆنتئێند
- 🎨 [Tailwind CSS](https://tailwindcss.com/) – ستایلی نوێی utility-first
- 🎯 [React Icons](https://react-icons.github.io/react-icons/) – کتێبخانەی ئایکۆن

## ⚙️ دەستپێکردن

بۆ کارپێکردنی ئەپەکە لەسەر کۆمپیوتەرەکەت ئەم هەنگاوانە بگرەبەر:

```bash
# 1. Clone the repository
git clone https://github.com/Ali-Umed/react-quiz-app.git
cd react-quiz-app

# 2. Install dependencies
npm install
npm start
```
