# 🔍 Kurdish OCR – Advanced Text Recognition

Kurdish OCR is a high-performance **Next.js** application specialized in extracting text from images and PDF documents with high precision. It is specifically optimized for **Kurdish (Sorani & Kurmanji)**, **Arabic**, and **English** languages, utilizing custom trained data models.

---

## ✨ Features

- 📑 **PDF & Image OCR** – Support for both image files and multi-page PDF documents.
- 🌍 **Multilingual Mastery** – Full support for Kurdish Sorani, Kurmanji, Arabic, and English.
- 🚀 **Specialized Models** – Uses custom-trained `.traineddata` models to ensure industry-leading accuracy for Kurdish scripts.
- 📄 **Granular Control** – Navigate through documents page by page with individual processing.
- 💾 **Versatile Exports** – Download text for specific pages or the entire document in one click.
- 📋 **Smart Copy** – Integrated clipboard management for quick text extraction.
- 🎨 **Premium UI/UX** – Developed with a sleek, modern aesthetic using **Tailwind CSS**.

---

## 🛠️ Tech Stack

- **Next.js** – For a fast, SEO-friendly web experience.
- **Tailwind CSS** – Modern, responsive design system.
---

## 🔑 Core Functionality

- **Document Parsing** – Upload multiple files and let the engine handle the rest.
- **Live Preview** – See results in real-time as the OCR engine processes each page.
- **Download & Copy** – Flexible options to export text per page or as a full document.
- **Responsive Design** – Fully functional across mobile, tablet, and desktop devices.
