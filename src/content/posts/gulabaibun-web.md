# 🌼 Gula Baibun Website — گوڵە بەیبوون

**Gula Baibun Website** is the official marketing and landing page for the **Gula Baibun** language learning app. Built with **Next.js 16** and **React 19**, it delivers a premium, SEO-optimized, and fully internationalized web experience designed to attract and convert users across Kurdistan and beyond.

> **🌐 A premium web presence for a premium learning experience — fast, beautiful, and multilingual.**

## ✨ Key Features

- **Premium Landing Page** – Stunning hero section with animated call-to-actions and app showcases
- **Phone Gallery Section** – Interactive carousel of real app screenshots with feature descriptions
- **Live Interactive Showcase** – Demonstrates the app's zero-latency word tapping system directly on the web
- **SEO-First Architecture** – Fully optimized meta tags, sitemap, robots.txt, and structured content for search engines
- **Multi-Language Support** – Full support for **Kurdish Sorani (کوردی)**, **English**, and **Arabic** with RTL layout
- **Dark & Light Theme** – Smooth HSL-based theme switching with system preference detection
- **Responsive Design** – Pixel-perfect layout from mobile to ultra-wide desktop
- **FAQ Section** – Accordion-style commonly asked questions
- **App Download Links** – Direct links to App Store and Google Play
- **Contact Page** – Contact form for user feedback and inquiries
- **Privacy Policy** – Comprehensive data protection and cookie policy page
- **About Page** – The story and philosophy behind Gula Baibun

---

## 💻 Frontend Highlights

The website is engineered for **speed, engagement, and discoverability**, using:

- **Next.js 16 (App Router)** – Server-side rendering with the latest App Router architecture for performance and SEO
- **React 19** – Leveraging the newest React features for a fast, component-driven UI
- **Tailwind CSS v4** – Utility-first styling with custom HSL-based design tokens for a cohesive dark/light theme
- **Framer Motion** – Rich micro-animations: staggered reveals, parallax effects, hover transitions, and scroll-triggered animations
- **next-intl** – Deep internationalization with locale-based routing (`/en`, `/ckb`, `/ar`)
- **Lucide React** – Modern, consistent icon system throughout the interface
- **Google Fonts (Inter)** – Clean, premium typography for a professional feel

## 🌐 Internationalization (i18n)

Full trilingual support with automatic locale detection and seamless switching:

| Language | Code | Direction | Status |
| :--- | :--- | :--- | :--- |
| **Kurdish Sorani** | `ckb` | RTL 🔄 | ✅ Full Support |
| **English** | `en` | LTR ➡️ | ✅ Full Support |
| **Arabic** | `ar` | RTL 🔄 | ✅ Full Support |

- Locale-based URL routing (`/en/`, `/ckb/`, `/ar/`)
- RTL layout support for Kurdish and Arabic
- Language switcher in navigation bar
- Cookie-based language persistence

## 🎨 Design System

The website uses a carefully crafted HSL-based design system:

- **Glassmorphic Cards** – Frosted glass effect with backdrop blur and transparency
- **Gradient Backgrounds** – Smooth multi-color gradients with blur effects
- **Micro-Animations** – Staggered fade-ins, scale transitions, hover lifts
- **Dark Mode First** – Premium dark theme as the default with smooth light mode toggle
- **Responsive Grid** – Fluid layouts that adapt from 320px mobile to 2560px ultrawide
